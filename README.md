## 🚀 Overview

Ini adalah repositori untuk website portofolio pribadi **I Gusti Ngurah Anom Hariyadi**. Situs ini dirancang sebagai pusat representasi digital perjalanan karir, keterampilan teknis, dan portofolio proyek. 

Dibangun dengan standar rekayasa perangkat lunak modern, website ini mengkombinasikan fungsionalitas tingkat tinggi dengan desain antarmuka yang sangat premium—menggabungkan gaya *Neobrutalism* pada mode terang (Light Mode) dan *Glassmorphism/Cyberpunk* pada mode gelap (Dark Mode).

## 🛠 Tech Stack

Website ini dibangun menggunakan teknologi web modern untuk performa dan interaktivitas maksimal:
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, GSAP, OGL (WebGL)
- **Icons:** Lucide React, React Icons
- **Image Processing:** Sharp (Custom built-in image compression script)

## ✨ Key Features

- **Dynamic Theme System:** Transisi mulus antara mode terang (Neo-brutalism) dan mode gelap (Glassmorphism/Aurora WebGL).
- **Micro-Interactions:** Animasi *ClickSpark*, *Hover Magnets*, *Logo Marquee*, dan *DotField* interaktif yang bereaksi terhadap kursor.
- **Ultra-Fast Image Gallery:** Dilengkapi dengan skrip kompresi otomatis (menurunkan ukuran gambar hingga 99%) dan implementasi *Progressive Lazy Loading* menggunakan `IntersectionObserver`.
- **Fully SEO Optimized:** Didukung oleh implementasi *OpenGraph*, *Twitter Cards*, *JSON-LD Rich Snippets*, *robots.txt*, dan struktur sitemap otomatis.
- **Responsive Design:** Tata letak sempurna untuk berbagai ukuran layar (Desktop, Tablet, Mobile) dengan menu *Dock* ala macOS.

## 💻 Getting Started (Menjalankan secara Lokal)

Ikuti instruksi berikut untuk menjalankan website ini di komputer lokal Anda:

### 1. Kloning Repositori
```bash
git clone https://github.com/rahtuanom/SelfWebsite.git
cd SelfWebsite
```

### 2. Install Dependensi
Pastikan Anda memiliki [Node.js](https://nodejs.org/) terinstal, kemudian jalankan:
```bash
npm install
```

### 3. Jalankan Development Server
Skrip kompresi galeri otomatis akan berjalan sebelum server menyala untuk memastikan semua gambar berukuran kecil siap digunakan.
```bash
npm run dev
```

### 4. Buka Browser
Buka tautan [http://localhost:3000](http://localhost:3000) di peramban Anda untuk melihat hasilnya.

## 🖼️ Penambahan Foto Galeri

Jika Anda ingin menambahkan foto dokumentasi ke dalam halaman **Gallery**, Anda tidak perlu melakukan kompresi secara manual!
1. Masukkan gambar orisinal berukuran penuh ke dalam folder `public/gallery/`
2. Jalankan `npm run dev` atau `npm run build`
3. Skrip otomatis akan membuat thumbnail berformat WebP (ukuran < 80 KB) di folder `public/gallery/thumbs/`
4. Gambar baru otomatis muncul dengan *lazy loading* yang super cepat!
